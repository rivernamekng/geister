# ガイスター

ボードゲーム「ガイスター」のスマホ向け Web アプリ。ビルド不要の静的サイトです。

- **CPU戦** — やさしい / ふつう / つよい
- **1台で2人対戦** — スマホを交代で渡す。手番の切り替えに目隠し画面が入ります
- **オンライン対戦** — 部屋を作って URL を送るだけ（Firebase の設定が必要）
- **再戦** — 対局後に「再戦する」「先攻後攻を交代して再戦」（CPU戦とオンライン対戦）
- **効果音とBGM** — 画面右上の「効果音」「BGM」で個別にオン・オフ。
  BGM は脱出口に駒が近づいたり捕獲が進んだりするとテンポが上がります

## 遊び方（ルール）

6×6 の盤に、各自8体のおばけを置きます。青が4体（良いおばけ）、赤が4体（悪いおばけ）。
**相手からは色が見えません。**

交代で、自分のおばけを縦か横に1マス動かします。相手のおばけがいるマスに入ると捕獲でき、
そのとき捕まえた駒の色が公開されます。

次のどれかを達成すると勝ちです。

1. 相手の青おばけを4体すべて捕まえる
2. 自分の赤おばけを4体すべて取らせる
3. 自分の青おばけを、相手陣のいちばん奥の左右どちらかの角から盤の外へ脱出させる

## 動かす

CPU戦と1台での対戦は、サーバーを立てるだけで遊べます（設定不要）。

```bash
python -m http.server 8777
```

ブラウザで `http://localhost:8777/` を開きます。
同じ Wi-Fi のスマホからは `http://<PCのIPアドレス>:8777/` で開けます。

## オンライン対戦の設定

オンライン対戦だけ Firebase Realtime Database を使います。無料枠で十分です。
Google アカウントがあれば、新しくアカウントを作る必要はありません。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作る
2. **Realtime Database** を作成する（ロケーションは asia-southeast1 などを選択、
   開始モードは **ロックモード** でかまいません。次の手順でルールを入れます）
3. Realtime Database の「ルール」タブに、このリポジトリの
   [`database.rules.json`](database.rules.json) の中身を貼り付けて公開する
4. **Authentication → Sign-in method** で **「匿名」** を有効にする
5. **プロジェクトの設定 → マイアプリ → ウェブアプリを追加** し、表示された
   `firebaseConfig` の値をコピーする
6. [`js/firebase-config.js`](js/firebase-config.js) の該当箇所に貼り付ける

設定が済むと、メニューの「オンラインで対戦」が使えるようになります。
片方が「部屋を作る」でコードと URL を受け取り、相手に送ります。
相手はその URL を開くか、コードを入力して参加します。

### 駒の色はサーバーに送られません

ガイスターは「相手に色を知られないこと」が肝なので、**自分の駒の色はこの端末から出ません**。
共有するのは指し手の列と、**捕獲されたときに持ち主が明かす1駒ぶんの色**だけです。
盤面は両者が同じ手順を並べ直して復元します。
そのため、通信内容やデータベースを覗いても、伏せられた駒の色は分かりません。

終局時に双方の配置を公開し、対局中に明かされた色と食い違っていたら結果画面に警告が出ます。

## 公開する（相手に URL を送れるようにする）

静的ファイルだけなので、どこに置いても動きます。

- **GitHub Pages** — リポジトリに push し、Settings → Pages で公開ブランチを指定
- **Firebase Hosting** — `firebase deploy`（Firebase CLI = Node.js が必要）
- **Netlify / Cloudflare Pages** — フォルダをドラッグ＆ドロップ

`js/firebase-config.js` の値は Web に公開されますが、Firebase の Web 設定は
もともと公開前提のものです。アクセス制御は `database.rules.json` 側で行います。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `js/rules.js` | ルールエンジン。盤面・合法手・捕獲・勝敗判定。純粋関数のみ |
| `js/ai.js` | CPU。相手の色を確率的に仮定した盤面を複数作って読む |
| `js/ui.js` | 盤と駒の描画、タップ入力 |
| `js/sound.js` | 効果音とBGM。音源ファイルは使わず Web Audio で合成 |
| `js/online.js` | 部屋・指し手の共有・盤面の復元 |
| `js/main.js` | 画面遷移と対局の進行 |
| `js/firebase-config.js` | Firebase の設定（自分で書き換える） |
| `database.rules.json` | Realtime Database のセキュリティルール |
| `tests.html` | ルール・CPU・同期のテスト。ブラウザで開くだけで走る |
| `tests-online.html` | オンライン対戦の結合テスト（擬似データベースを使用） |

## テスト

サーバーを立てた状態で、ブラウザで開くだけで走ります。

- `http://localhost:8777/tests.html` — ルール、CPU、指し手の並べ直し
- `http://localhost:8777/tests-online.html` — 部屋づくりから捕獲・色の公開までの一連の流れ
  （Firebase の代わりにメモリ上の擬似データベースを使うので、設定なしで走ります）

## 既知の制約

- オンライン対戦中に相手がアプリを閉じると、捕獲された駒の色が公開されず
  「相手の応答を待っています」で止まります。相手が同じ URL を開き直せば再開できます。
- 対局の再開は同じ端末・同じブラウザでのみ可能です（自分の配置を端末内に保存しているため）。
- 相手が不正なクライアントを使えば、明かす色を偽ることはできます。
  終局時の照合で気づける程度の対策に留めています。
